# Seguridad y uso responsable

Este proyecto automatiza una tienda pública de práctica. Las cuentas y la
contraseña de `test-data/demo.ts` están publicadas por SauceDemo. No son secretos
del propietario de este repositorio.

Utiliza únicamente datos ficticios. No introducir información personal, documentos,
pagos ni cuentas de producción. La URL de pruebas está fijada a la demo.

No se guardan claves de GitHub ni credenciales personales en el código. Los
reportes brutos, estados de autenticación, dependencias y variables privadas están
excluidos de Git. Las trazas pueden contener datos de sesión; revisar siempre su
contenido antes de compartirlas fuera del entorno de práctica.

GitHub Actions tiene permiso `contents: read`; no utiliza secretos, no despliega
cambios ni publica automáticamente reportes en un sitio. Los artefactos se
conservan 14 días. No se ejecutan tareas programadas ni pruebas de carga contra
el proveedor.

Para comunicar información sensible sobre este repositorio, contactar de forma
privada mediante [LinkedIn](https://www.linkedin.com/in/santiago-atehortua-soto-baa56a308/).
No pegar credenciales o datos personales en incidencias públicas.
